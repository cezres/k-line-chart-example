# K-line Chart Example

使用 `CustomPainter` 自绘K线图。

**[K-line Chart Example Web 页面](https://flutter-k-line-chart-example.github.io/)** (由于跨域使用固定时段数据)。

### 如何运行

```bash
$ flutter pub get
$ flutter run
```
